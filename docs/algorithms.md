# 자료구조·경로탐색

2020년 자료구조·알고리즘 교과에서 BST, Red-Black Tree, tester와 Dijkstra·A* 경로탐색을 구현했습니다.

## 트리

삽입·삭제에 따라 노드를 연결하고 자료구조의 조건을 유지하는 과정을 다뤘습니다. BST와 Red-Black Tree를 구현하고 tester로 연산을 확인했습니다.

## 경로탐색

지도와 시작·목표 위치를 입력받아 경로를 탐색하는 코드를 작성했습니다. Dijkstra의 누적 비용 탐색과 A*의 목표 방향 추정이 탐색 순서에 미치는 차이를 학습했습니다.

이 문서는 구현 경험을 설명하며, 관련 코드는 저장소에 포함되어 있지 않습니다.
